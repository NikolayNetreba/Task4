# Стековый процессор

# Постановка задачи:
- :white_check_mark: Реализовать стековый процессор
- :white_check_mark: Сделать валидацию ошибок
- :white_check_mark: Сделать отладочный режим, во время которого выводится все содержимое процессора на каждой итерации процессора
- :white_check_mark: Реализовать свой ассемблер
- :white_check_mark: Написать на своем ассемблере: фактариал, квадратку, вывод кружочка

# Общая архитектура
```spu
.
├── include
|   ├── assembly.h
|   ├── colors.h
|   ├── config.h
|   ├── stack.h
|   ├── commands.h
|   └── spu.h
|
├── src
|   ├── assembly.cpp
|   ├── commands.cpp
|   ├── stack.cpp
|   └── spu.cpp
|
├── byte_code.bin
├── input.txt
└── spu_dump.txt
```

Выбор типа данных, формат вывода, значение по умолчанию задаются в ```config.h```. В ```stack.h``` описана логика стека и отладочного режима.

# Компиляция и запуск
- Можно скомпилировать используя makefile - make.
- И запустить -./assembler ./spu
- Чтобы включить отладочный режим нужно использовать флаг: ```-DDEBUG```

# Фичи
- **Богоподобный dump:** Полная распечатка процессора на каждой итерации - дамп основного стека, стека вызовов, значений регистров и памяти. С подсветкой текущей выполняемой команды.
- **Собственный двухпроходный ассемблер:** Поддержка текстовых меток (labels), а также поддержка комментариев в коде.


## Память и регистры
- **Регистры:** Процессор поддерживает 4 регистра: `AX`, `BX`, `CX`, `JF`.
- **RAM:** Оперативная память размером `1024` ячеек. Обращение к памяти происходит через квадратные скобки: `PUSH [10]`, `POP [bx]` и `PUSH [10 + AX]`.
- **бинарник и защита от дурака:** ассемблер создает бинарник (`byte_code.bin`) по сигнатуре и версии. Защита от Stack Overflow/Underflow, деления на ноль и выхода за пределы RAM.

## Структура бинарного файла
1. **Сигнатура:** 4 байта.
2. **Версия ассемблера:** 4 байт.
3. **Размер кода** 4 байта (размер исполняемого кода).
4. **Массив байткода:** сами инструкции и их аргументы.

## Поддерживаемые команды

### Базовые операции, работа со стеком
* **`PUSH`** - кладет аргумент на стек (возможные аргументы: `const`, `register`, `RAM`).
* **`POP`** - забирает верхнее значение стека (возможные аргументы: `register`, `RAM`).
* **`OUT`** - выводит верхнее значение стека в консоль.
* **`IN`** - считывает значение со стандартного ввода (клавиатуры) и кладет его на стек.
* **`HLT`** - завершает выполнение кода.

### Арифметические операции
* **`ADD`** - складывает два верхних элемента стека.
* **`SUB`** - вычитает верхний элемент стека из предпоследнего.
* **`MUL`** - умножает два верхних элемента стека.
* **`DIV`** - делит предпоследний элемент стека на верхний.
* **`SQRT`** - извлекает квадратный корень из верхнего элемента стека.

### Условные и безусловные переходы
*Условные переходы сравнивают два верхних элемента стека и совершают переход по указанному адресу при выполнении условия.*
* **`JMP`** - безусловный переход по указанному адресу.
* **`JA`** - переход, если первый элемент строго больше второго (`>`).
* **`JB`** - переход, если первый элемент строго меньше второго (`<`).
* **`JE`**  - переход, если элементы равны (`==`).
* **`JAE`** - переход, если первый элемент больше или равен второму (`>=`).
* **`JBE`**  - переход, если первый элемент меньше или равен второму (`<=`).
* **`JNE`** - переход, если элементы не равны (`!=`).

### Функции и специальные операции
* **`CALL`** - вызов функции. Сохраняет адрес следующей инструкции и переходит к указанной метке.
* **`RET`** - возврат из функции. Извлекает адрес возврата и переходит по нему.
* **`DISC`** - вычисляет дискриминант квадратного уравнения (или отрисовывает графику/display).
* **`PRAM`** *(Print RAM)* - выводит содержимое оперативной памяти (используется для отладки).

### Метки и комментарии
* **`:mark`** - метка состоять из любых симполов кроме `#`
* **`# comment`** - коментарий

### Примеры кода
Этот код выводит факториал числа.
```
IN AX
PUSH AX
CALL :fact

OUT
HLT

:fact
POP AX

PUSH AX
PUSH 1
JE :base #if AX = 1

PUSH AX

PUSH AX
PUSH 1
SUB

CALL :fact

POP BX
POP AX
PUSH BX
PUSH AX

MUL # fact(N - 1)* N
RET

:base
PUSH 1
RET
```
